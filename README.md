# Sales Data Analysis & Excel Dashboard

## Project Overview

This project focuses on analyzing a sales dataset and transforming raw business data into a structured and interactive reporting solution using Microsoft Excel.

The project covers data cleaning, customer data standardization, order and delivery analysis, product analysis, sales analysis, statistical analysis, financial calculations, data validation, and dashboard development.

The final output is an interactive Sales Dashboard designed to provide a clear overview of business performance.

## Business Objective

The main objectives of this project were:

- Clean and standardize raw sales data.
- Improve the consistency and quality of customer information.
- Analyze sales performance across different regions and categories.
- Analyze order and delivery performance.
- Evaluate product revenue, pricing, and discount performance.
- Perform statistical and financial calculations.
- Build an interactive dashboard for business reporting.

---

## Data Preparation and Cleaning

The dataset was cleaned and prepared before performing the analysis.

Key activities included:

- Removed duplicate Order IDs.
- Handled missing Order Dates and Delivery Dates.
- Replaced missing Salesperson values with "Not Assigned".
- Removed unnecessary spaces from customer names.
- Standardized customer names using Proper Case.
- Standardized Region and Category values.
- Corrected inconsistent category names.
- Standardized email IDs.
- Identified invalid email addresses.
- Applied data validation rules.
- Used conditional formatting to identify high-discount orders.

---

## Customer Data Analysis

Customer-related analysis included:

- Customer name standardization.
- Customer age calculation using Date of Birth.
- Customer Code creation using customer and location information.
- Email ID cleaning and standardization.
- Identification of invalid email addresses.

---

## Order and Delivery Analysis

Order and delivery performance was analyzed using:

- Customer Age
- Delivery Time
- Delivery Status

Orders were classified into:

- On Time
- Delayed
- Pending

This analysis helps evaluate order fulfillment and delivery performance.

---

## Product Analysis

A Product Lookup Report was created using Product ID.

The lookup system retrieves:

- Product Name
- Category
- Supplier
- Cost Price
- Warranty

Additional product-level calculations included:

- Total Revenue
- Weighted Average Unit Price
- Difference between calculated revenue and existing Sales
- Total Discounted Amount

---

## Sales Analysis

Sales performance was analyzed using Excel formulas and Pivot Tables.

The analysis covered:

- Sales by Region
- Sales by Category
- Salesperson performance
- Order Status analysis
- Discount-based order analysis
- Payment Mode analysis
- Customer rating analysis
- Average sales under specific business conditions
